# نسخه تست نهایی مسیر ۲۸ روزه بازسازی ذهن — نسخه ۳۸

این نسخه برای تست نهایی رابط کاربری و منطق برنامه آماده شده است.

## موارد اصلاح‌شده
- مسیر شروع: صفحه نخست ← ثبت پرونده ← ارزیابی اولیه ← تصویر وضعیت امروز ← روز ۱
- دکمه «بازگشت» داخل روزها مستقیماً به «ثبت پرونده» می‌رود.
- حرکت ثبت امروز و رفتن به روز بعد برای روزهای مسیر پایدار شده است.
- برگشت به روز قبل و سپس ادامه دوباره به جلو حفظ شده است.
- پایان روز ۲۸ در یک صفحه مستقل نمایش داده می‌شود و سپس ارزیابی نهایی باز می‌شود.
- «شروع مسیر تازه» از ثبت پرونده شروع می‌شود و اطلاعات مسیر قبلی را برای مسیر جدید پاک می‌کند.
- اگر بازخورد دو روز پشت سر هم مشابه باشد، راهبرد روز بعد تغییر می‌کند؛ حتی اگر نمره‌ها یکسان نباشند.
- بازخورد «فردا تمرین متفاوت باشد» نیز باعث تغییر راهبرد می‌شود.
- منطق پیشنهاد خدمات نهایی حفظ شده: زیر ۱۰، ۱۰ تا کمتر از ۳۰، ۳۰ تا کمتر از ۶۰، ۶۰ تا کمتر از ۹۰، و ۹۰ به بالا؛ هیپنوتراپی حضوری فقط برای سن ۲۳ تا ۶۳ سال.
- کتابخانه با عنوان «کتابخانه اختصاصی» باقی مانده و متن هر دو جلد به‌صورت سبک و مرحله‌ای بارگذاری می‌شود.
- هدر و فوتر تکراری PDF وارد متن کتاب‌خوان نمی‌شود.
- تصاویر جلد و لوگو برای کاهش حجم اولیه به WebP تبدیل شده‌اند.
- Telegram Mini App SDK و Safe Area/Back Button برای محیط Telegram اضافه شده است.
- content.json کنار index.html قرار گرفته تا در GitHub درخواست 404 اضافی ایجاد نشود.
- شناسه‌های HTML، JSON کتاب‌ها، PDFها و لینک‌های محلی بررسی شده‌اند.

## نکته مهم درباره پرداخت
سیستم فروش و پرداخت دیجیتال عمداً در این نسخه فعال نشده است و کتاب‌ها برای تست، قابل مشاهده‌اند. اتصال پولی و کنترل دسترسی تجاری در مرحله بعد انجام می‌شود.

## تست پیشنهادی
1. صفحه نخست → شروع و تشکیل پرونده.
2. ثبت پرونده → ارزیابی اولیه → تصویر وضعیت → روز ۱.
3. چند روز را کامل کن و با «روز قبل» به عقب برگرد؛ سپس دوباره جلو برو.
4. سناریوی مهم: روز ۱۵ → ثبت امروز → روز ۱۶ → روز ۱۵ → روز ۱۶.
5. روز ۲۸ → «ثبت امروز و رفتن به روز بعد» → صفحه پایان مستقل → «رفتن به ارزیابی نهایی».
6. ارزیابی نهایی → مشاهده پیشنهاد ادامه مسیر.
7. از داشبورد پس از پایان، «شروع مسیر تازه» را بزن؛ باید ابتدا به ثبت پرونده برگردد.
8. «کتابخانه اختصاصی» → جلد ۱ و جلد ۲ → جستجو، فهرست، تغییر اندازه متن، صفحه قبل/بعد و ادامه مطالعه.
9. «پشتیبانی و نوبت‌دهی» و لینک کانال مرکز را جداگانه تست کن.

این نسخه هنوز نسخه تجاری پرداخت‌دار نیست.
