نسخه V22 Adaptive Checked

منطق روزانه بازطراحی شده است:
- روز اول محتوای پایه همان مشکل انتخاب‌شده را دریافت می‌کند.
- از روز دوم، نمره ۰ تا ۱۰ و تجربه روز قبل در انتخاب تمرین و راهکار روز بعد دخالت می‌کنند.
- اگر دو روز پیاپی بازخورد یکسان ثبت شود، روز بعد راهبرد جایگزین همان مشکل انتخاب می‌شود و محتوای روز قبل تکرار نمی‌شود.
- اگر تجربه روز قبل عدم اثربخشی را نشان دهد، راهبرد جایگزین فعال می‌شود.
- این منطق برای تمام ۳۴ مشکل و تمام روزهای ۱ تا ۲۸ اعمال شده است.
