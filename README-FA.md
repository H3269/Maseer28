# مسیر ۲۸ روزه بازسازی ذهن — V20 PRO

نسخه بازطراحی‌شده منطق برنامه با ۳۴ مسیر مستقل.

## معماری
- کاربر جدید: صفحه شروع → شروع مسیر ۲۸ روزه → تشکیل پرونده.
- کاربر قبلی: وضعیت مسیر حفظ می‌شود.
- هر یک از ۳۴ گزینه مشکل، کلید محتوایی مستقل دارد.
- هر مسیر شامل ۲۸ تمرین و ۲۸ راهکار اختصاصی است.
- پاسخ روزانه و شدت ۰ تا ۱۰ در انتخاب محتوای روز بعد اثر می‌گذارند.
- روز بعد بر اساس چهار حالت تنظیم، تثبیت، بررسی و پیشروی تعدیل می‌شود.
- روزهای آینده تا تکمیل روز جاری قفل هستند.
- روز ۲۸ به ارزیابی نهایی متصل است.
- کادرهای پاسخ روزانه و ارزیابی نهایی فقط متن فارسی را می‌پذیرند.

این برنامه آموزشی و خودمشاهده‌ای است و جایگزین تشخیص، درمان یا ارزیابی تخصصی سلامت روان نیست.
