# مسیر ۲۸ روزه بازسازی ذهن — نسخه ۲۶

این نسخه برای Telegram Mini App و GitHub Pages طراحی شده است.

ویژگی‌های اصلی:
- صفحه شروع برندشده با لوگوی مرکز و دو دکمه فعال
- فرم ثبت پرونده با محدودیت‌های فارسی/انگلیسی و عددی
- ۳۴ دسته مشکل
- تمرین و راهکار عملی کاملاً جدا از هم
- ۲۸ روز بدون نمایش محتوای روز بعد در صفحه روز جاری
- استفاده از مشکل، هدف و ارزیابی اولیه در شخصی‌سازی
- استفاده از نمره روزانه و تجربه فارسی کاربر برای انتخاب روز بعد
- تغییر راهبرد در صورت بازخورد منفی یا تکرار دو روزه
- جلوگیری از تکرار محتوای نمایش‌داده‌شده تا حد امکان
- ارزیابی نهایی با سؤال پنجم متفاوت از فرم اولیه
- بدون کتابخانه یا فایل جاوااسکریپت خارجی؛ برای اجرای سبک‌تر

نکته: این برنامه آموزشی و خودمشاهده‌ای است و جایگزین تشخیص یا درمان تخصصی نیست.
