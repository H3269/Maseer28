# مسیر ۲۸ روزه بازسازی ذهن — نسخه نهایی V18

این بسته برای بارگذاری مستقیم در ریشه Repository گیت‌هاب و اجرای GitHub Pages آماده شده است.

## تغییرات اصلی V18
- صفحه اول Mini App یک دکمه بزرگ و واضح «🚀 شروع مسیر ۲۸ روزه بازسازی ذهن» دارد و قبل از تشکیل پرونده نمایش داده می‌شود.
- نام و نام خانوادگی فقط با حروف فارسی یا فقط با حروف انگلیسی پذیرفته می‌شود؛ ترکیب دو زبان، عدد و علامت رد می‌شود و حداکثر ۵۰ کاراکتر دارد.
- سن فقط عدد فارسی یا فقط عدد انگلیسی از ۱ تا ۱۲۰ است؛ ترکیب دو نوع عدد و علامت رد می‌شود.
- مشکل اصلی از حالت تایپ خارج و به فهرست کشویی تبدیل شده است. گزینه‌ها شامل خشم، اضطراب، ترس، نفرت، حسادت، غم و سوگ، احساس گناه، اعتمادبه‌نفس، افکار منفی و نشخوار، وابستگی عاطفی، اهمال‌کاری، خواب، عادت، مرزبندی، تنهایی، انگیزه، رابطه و موضوع عمومی هستند.
- انتخاب مشکل مستقیماً دسته محتوایی و تمرین/راهکار ۲۸ روزه مربوط به همان موضوع را تعیین می‌کند.
- پاسخ روزانه حداکثر ۱۰۰۰ کاراکتر است و فقط حروف و کلمات فارسی به همراه فاصله و نشانه‌های نگارشی مجاز را می‌پذیرد؛ حروف انگلیسی و عدد رد می‌شوند.
- شدت روزانه فقط عدد ۰ تا ۱۰ و از یک نوع رقم (فارسی یا انگلیسی) پذیرفته می‌شود.
- از روز ۲ تا ۲۸، تمرین و راهکار روز بعد بر اساس شدت ثبت‌شده روز قبل و محتوای پاسخ روز قبل به‌صورت تطبیقی تنظیم می‌شود.
- بازخورد روزانه نیز توضیح می‌دهد که برنامه روز بعد بر اساس داده همان روز تنظیم شده است.
- منطق استمرار، مراقبه، ارزیابی اولیه و نهایی، داشبورد و شروع مجدد دوره حفظ شده‌اند.

## فایل‌ها
- `index.html` — اپ اصلی و خودکفا
- `logo.png` — لوگوی مرکز هیپنوتراپی شفا
- `content.json` — بانک محتوای قابل مشاهده
- `VERSION.txt` — اطلاعات نسخه

## بارگذاری روی GitHub
محتویات این ZIP را استخراج کنید و فایل‌ها را در ریشه Repository قرار دهید؛ خود ZIP را داخل Repository به‌عنوان فایل اجرایی قرار ندهید. `index.html` باید در ریشه پروژه باشد تا GitHub Pages آن را به‌عنوان صفحه اصلی اجرا کند.
