# مسیر ۲۸ روزه بازسازی ذهن — نسخه نهایی v30

اصلاحات نهایی: مدت درگیری سال/ماه، شرایط پزشکی و گزینه‌های مستقل کلامی و شنیداری، دارو و نام دارو، بازخورد چندانتخابی، توضیح نمره ۰ تا ۱۰، اثر بازخورد و نمره بر روز بعد، جلوگیری از تکرار، اصلاح ادامه مسیر، لینک مستقیم مراقبه، و حفظ داشبورد/کانال/کتاب‌ها/پشتیبانی.
