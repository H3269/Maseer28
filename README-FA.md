# مسیر ۲۸ روزه بازسازی ذهن — نسخه نهایی V2

این بسته برای بارگذاری روی GitHub آماده شده است.

## فایل‌ها
- `index.html` — اپ اصلی و خودکفا
- `logo.png` — لوگوی مرکز هیپنوتراپی شفا
- `content.json` — نسخه قابل مشاهده بانک محتوای برنامه
- `VERSION.txt` — اطلاعات نسخه

## اصلاحات این نسخه
- تمرین امروز و راهکار عملی امروز از هم جدا و در ۲۸ مرحله متفاوت شده‌اند.
- راهکار تکمیلی بازخورد از راهکار واقعی همان روز تغذیه می‌شود و تکراری ثابت نیست.
- شدت روزانه مشکل از ۰ تا ۱۰ ثبت می‌شود و بازخورد روز بعد نسبت به روز قبل تغییر می‌کند.
- در پایان مسیر دکمه «شروع دوباره مسیر ۲۸ روزه» برای ارزیابی یک مشکل جدید وجود دارد.
- نتیجه نهایی مطابق بازه‌های جدید درخواست‌شده نمایش داده می‌شود.
- امتیاز ۱۰۰ پیام تبریک و جمله ماندگار نمایش می‌دهد.
- لوگوی مرکز در سرصفحه قرار گرفته است.
- دکمه ورود به کانال مرکز هیپنوتراپی شفا زیر کتاب‌ها اضافه شده است.
- مراقبه قطع لینک و شرط استمرار مسیر حفظ شده‌اند.
- دکمه پیامک همچنان حذف شده تا خطای خروج از اپ تکرار نشود.

## بارگذاری
فایل‌ها را در ریشه Repository قرار دهید و `index.html` را به عنوان صفحه اصلی GitHub Pages معرفی کنید.
