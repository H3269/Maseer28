مسیر ۲۸ روزه — Telegram Mini App MVP

این نسخه از Telegram Web Apps SDK استفاده می‌کند و برای اجرا در داخل Telegram طراحی شده است.
نسخه فعلی شامل روز صفر، روز اول، ثبت تمرین، پیشرفت، تشخیص آنلاین/آفلاین و نمایش نام کاربر تلگرام است.

هشدار:
این نسخه هنوز برای اطلاعات واقعی مراجعان مناسب نیست؛ داده‌ها در localStorage دستگاه ذخیره می‌شوند و سرور/احراز هویت/رمزنگاری/پنل درمانگر/پرداخت واقعی ندارد.

راه‌اندازی:
1) فایل ZIP را باز کنید.
2) index.html و manifest.webmanifest را در یک مخزن GitHub قرار دهید.
3) GitHub Pages را برای شاخه اصلی فعال کنید.
4) آدرس HTTPS ساخته‌شده را بردارید.
5) در @BotFather برای ربات خود: Bot Settings > Configure Mini App > Enable Mini App را انتخاب و همان HTTPS URL را ثبت کنید.
6) سپس در BotFather برای ربات، Main Mini App را تنظیم کنید.
7) از پروفایل ربات یا لینک مستقیم Mini App آن را باز و تست کنید.

برای نسخه واقعی باید یک backend امن اضافه شود و اطلاعات حساس مراجعان روی GitHub Pages/localStorage نگهداری نشود.
